# Danh Sách Tính Năng (Features)

1. **Xác thực & Người dùng**: Đăng ký, đăng nhập (JWT), quên mật khẩu, quản lý hồ sơ cá nhân.
2. **Quản trị Danh mục**: Tạo cây danh mục cha-con cho Bài viết (Posts) và Sản phẩm (Products).
3. **Bài viết (Posts)**: Soạn thảo, upload ảnh, quy trình duyệt (DRAFT -> PENDING -> PUBLISHED).
4. **Sản phẩm (Products)**: Quản lý thông tin, thư viện ảnh (gallery), thông số kỹ thuật (specs) linh hoạt.
5. **Review Sản phẩm**: Viết bài review chi tiết, đánh giá ưu/nhược điểm (Pros/Cons), chấm điểm theo tiêu chí.
6. **Bình luận (Comments)**: Bình luận đa cấp (nested), reply, report vi phạm, duyệt/ẩn bình luận.
7. **Đánh giá sao (Rating)**: Chấm sao 1-5 cho sản phẩm (mỗi user 1 lần/sản phẩm), tính trung bình.
8. **AI Sentiment & Analytics**: Tự động phân tích comment (POS/NEG/NEU), tóm tắt kết luận sản phẩm, cấu hình ngưỡng duyệt AI.
9. **Tương tác**: Yêu thích (Favorite), So sánh sản phẩm (Compare list), Nội dung nổi bật (Featured).
10. **Thống kê**: Tracking lượt xem (Page views), Dashboard Admin tổng quan.
