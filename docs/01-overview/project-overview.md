# Project Overview

## 1. Project Name
Tech Blog Java – Tech Review Platform

## 2. Project Description

Tech Blog Java là một nền tảng web cho phép người dùng:

- Đọc bài viết công nghệ
- Xem review sản phẩm
- So sánh sản phẩm
- Đánh giá và bình luận
- Phân tích cảm xúc bình luận bằng AI

Hệ thống được xây dựng nhằm cung cấp một nền tảng đánh giá sản phẩm công nghệ minh bạch và có dữ liệu tổng hợp từ cộng đồng.

Backend được phát triển bằng **Spring Boot + MySQL** theo kiến trúc REST API.

---

## 3. Core Objectives

Mục tiêu chính của hệ thống:

1. Cung cấp nền tảng review sản phẩm công nghệ
2. Cho phép cộng đồng tham gia đánh giá và bình luận
3. Tổng hợp dữ liệu đánh giá từ người dùng
4. Phân tích sentiment của bình luận bằng AI
5. Hỗ trợ quản trị nội dung qua hệ thống CMS

---

## 4. Main Actors

### Guest
- Xem sản phẩm
- Xem bài viết
- Xem review

### User
- Bình luận
- Đánh giá sản phẩm
- Thêm vào danh sách yêu thích
- So sánh sản phẩm

### Author
- Viết bài review
- Gửi bài review để admin duyệt

### Admin
- Quản lý user
- Quản lý sản phẩm
- Quản lý bài viết
- Kiểm duyệt review
- Kiểm duyệt comment
- Quản lý AI sentiment

---

## 5. System Value

Hệ thống mang lại các giá trị:

- Nội dung review chất lượng
- Thông tin sản phẩm rõ ràng
- Phân tích đánh giá cộng đồng
- Hệ thống quản trị nội dung hoàn chỉnh
- Nền tảng mở rộng cho các tính năng AI

---

## 6. Technology Stack

Backend:

- Java
- Spring Boot
- Spring Security
- JWT Authentication
- Spring Data JPA
- MySQL

Tools:

- Maven
- Swagger / OpenAPI
- Git

Hệ thống bao gồm:
