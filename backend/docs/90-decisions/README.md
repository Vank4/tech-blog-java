# (ADR) - Nhật ký Quyết Định Kiến Trúc Và Hệ Thống

Thư mục lưu trữ bằng chứng và logic tranh luận về các Quyết Định Kiến Trúc (Architecture Decision Records - ADR) qua các phase làm dự án. Đây là nhật trình bảo tàng lại tư duy của Team Member.

Luật viết ADR: Bất cứ khi nào Tech Lead hoặc Team có sự đồng bộ chọn thư viện lib mới, Framework mới mẻ lớn, mô hình Cache Database, Kiến trúc Microservice Cloud Deployment, hãy bổ sung log tạo file `.md` mới.

Cấu trúc nội dung cơ bản của một file ADR tại đây:
1. **Context (Bối Cảnh Vấn đề)**: Bài toán khó tại thời điểm đó là gì.
2. **Decision (Dứt Điểm Lựa chọn Mũi nhọn)**: Tên đồ nghề kỹ thuật, API framework xử lý.
3. **Consequence (Hệ quả Vận Hành)**: Cả nhóm đánh rủi ro gì ở kiến trúc đó không? Mặt tốt lợi ích bù trừ là gì.
